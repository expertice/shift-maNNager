## Структура базы данных системы планирования смен и отпусков

### **Основные таблицы системы**

#### **1. users** — Суперпользователи системы

| Поле | Тип | Описание |
| :-- | :-- | :-- |
| id | UUID/INT | Первичный ключ |
| email | VARCHAR(255) | Email для входа (уникальный) |
| password_hash | VARCHAR(255) | Хеш пароля |
| created_at | TIMESTAMP | Дата создания |

#### **2. schedules** — Схемы планирования

| Поле | Тип | Описание |
| :-- | :-- | :-- |
| id | UUID/INT | Первичный ключ |
| owner_user_id | UUID/INT FK | Владелец схемы (суперпользователь) |
| name | VARCHAR(255) | Название схемы |
| start_date | DATE | Начало периода планирования |
| end_date | DATE | Конец периода планирования |
| status | ENUM | 'draft', 'published', 'completed', 'archived' |
| created_at | TIMESTAMP | Дата создания |
| updated_at | TIMESTAMP | Дата последнего изменения |

#### **3. schedule_permissions** — Права доступа к схемам

| Поле | Тип | Описание |
| :-- | :-- | :-- |
| id | UUID/INT | Первичный ключ |
| schedule_id | UUID/INT FK | Схема |
| user_id | UUID/INT FK | Пользователь (суперпользователь) |
| role | ENUM | 'owner', 'editor', 'viewer' |
| created_at | TIMESTAMP | Дата предоставления доступа |

### **Профили смен и типы смен**

#### **7. shift_profiles** — Профили смен (глобальные шаблоны)

| Поле | Тип | Описание |
| :-- | :-- | :-- |
| id | UUID/INT | Первичный ключ |
| name | VARCHAR(255) | Название (например, '2/2', '3/3', '5/2') |
| cycle_length | INT | Длина цикла в днях (для 2/2 это 4) |
| min_employees | INT | Минимальное количество сотрудников |
| description | TEXT | Описание профиля |

#### **8. shift_types** — Типы смен в профилях

| Поле | Тип | Описание |
| :-- | :-- | :-- |
| id | UUID/INT | Первичный ключ |
| shift_profile_id | UUID/INT FK | Профиль смены |
| name | VARCHAR(255) | Название (например, 'день', 'ночь') |
| start_time | TIME | Время начала |
| end_time | TIME | Время окончания |
| breaks | JSON | Массив перерывов [{start, end, duration}, ...] |
| night_hours_count | INT | Количество ночных часов (22:00-06:00) |
| working_hours | DECIMAL | Общее количество рабочих часов |

#### **9. shift_profile_patterns** — Паттерны в профилях смен

| Поле | Тип | Описание |
| :-- | :-- | :-- |
| id | UUID/INT | Первичный ключ |
| shift_profile_id | UUID/INT FK | Профиль смены |
| pattern_number | INT | Номер паттерна (1, 2, 3, 4 для 2/2) |
| cycle_length | INT | Длина цикла (повторяется каждые N дней) |
| sequence | JSON | Массив типов смен [shift_type_id, shift_type_id, ...] или null для отдыха |

## **Ключевые особенности структуры**

1. **Многопользовательская архитектура**: Каждая схема имеет владельца и может быть доступна другим суперпользователям через `schedule_permissions`
2. **Иерархия смен**: Профиль смены → Типы смен → Паттерны → Назначения → Ежедневные смены
3. **Гибкость назначений**: Система поддерживает как автоматическое разворачивание паттернов, так и ручное редактирование смен
4. **Управление конфликтами**: Система отслеживает конфликты и предлагает несколько вариантов решения
5. **Полная история**: Все изменения сохраняются для аудита и отката на нужную версию
6. **Анализ нагрузки**: Таблица `work_hour_tracking` позволяет сравнивать варианты расписания и контролировать равномерность нагрузки
