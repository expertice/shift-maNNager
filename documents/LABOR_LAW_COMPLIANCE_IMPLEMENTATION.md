## API Endpoints

### Настройки
- `GET /api/v1/labor-law/settings` - получить настройки
- `PUT /api/v1/labor-law/settings` - обновить настройки

### Нормы часов
- `GET /api/v1/labor-law/work-hours-norms` - все нормы
- `GET /api/v1/labor-law/work-hours-norms/:year` - норма для года
- `PUT /api/v1/labor-law/work-hours-norms/:year` - обновить норму вручную
- `POST /api/v1/labor-law/work-hours-norms/:year/sync` - синхронизировать
- `POST /api/v1/labor-law/work-hours-norms/:year/calculate` - пересчитать

### Валидация
- `POST /api/v1/labor-law/validate/:scheduleId` - запустить проверку
- `GET /api/v1/labor-law/violations/:scheduleId` - получить нарушения
- `PUT /api/v1/labor-law/violations/:violationId/resolve` - отметить решенным
- `GET /api/v1/labor-law/violations/:scheduleId/stats` - статистика

## Основные возможности

### 1. Настройки контроля (единые для всех расписаний)
- Максимальная продолжительность смены (12 часов по умолчанию)
- Минимальные межсменные интервалы (зависят от продолжительности смены)
- Норма часов: недельная (40 ч), месячная (166.67 ч), квартальная (500 ч)
- Допустимое превышение часов в год (120 часов сверхурочных)
- Настройка ночных часов (22:00-06:00)
- Максимум рабочих дней подряд (6 дней)
- Включение/отключение отдельных правил проверки

### 2. Нормы рабочего времени
- Автоматический расчет из производственного календаря РФ
- Возможность ручной корректировки с сохранением флага
- Хранение норм по годам
- Метаданные: праздники, переносы, количество рабочих дней

### 3. Отчетные периоды и переработки
Для каждого расписания настраивается:
- Отчетный период: неделя/месяц/квартал
- Флаги "Допустить переработку":
  - `allowOvertimeWeekly` - для недели
  - `allowOvertimeMonthly` - для месяца
  - `allowOvertimeQuarterly` - для квартала

Если флаг установлен - проверка переработок для данного периода отключается.

### 4. Автоматическая валидация
- Автоматически запускается при сохранении расписаний в статусе "draft"
- Автоматически запускается после массового создания смен
- Асинхронное выполнение (не блокирует основные операции)

### 5. Типы нарушений
- `excessive_shift_hours` - превышение продолжительности смены
- `insufficient_rest` - недостаточный межсменный отдых
- `excessive_weekly_hours` - превышение недельной нормы
- `excessive_monthly_hours` - превышение месячной нормы
- `excessive_quarterly_hours` - превышение квартальной нормы
- `excessive_yearly_hours` - превышение годовой нормы (+ сверхурочные)
- `excessive_consecutive_days` - превышение рабочих дней подряд
- `excessive_night_shifts` - превышение ночных смен в неделю

### 6. Критичность нарушений
- `critical` - критическое нарушение (красный цвет)
- `warning` - предупреждение (желтый цвет)
- `info` - информационное (синий цвет)

## Статьи ТК РФ

Реализованные проверки основаны на:
- **Ст. 91** - продолжительность рабочего времени (40 часов в неделю)
- **Ст. 94** - максимальная продолжительность ежедневной работы (12 часов)
- **Ст. 96** - работа в ночное время (22:00-06:00)
- **Ст. 99** - сверхурочная работа (не более 120 часов в год, не более 4 часов в течение двух дней подряд)
- **Ст. 108** - перерывы для отдыха и питания
- **Ст. 110** - еженедельный непрерывный отдых (не менее 42 часов)
